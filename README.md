# Odin Recipes

My first HTML project, created as part of The Odin Project Foundations course.

## About

A simple recipe website with three recipes. Each recipe has an image, a description, an ingredients list, and step-by-step cooking instructions.

## Skills

- Basic HTML structure and semantic elements
- Working with links, images, and lists
- Using relative file paths
- Git and GitHub version control
- Deploying a website with GitHub Pages
